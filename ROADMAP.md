# Roadmap

## Available: manifest prototype with LIV adapter

- Explicit sample relationships, local JSON result links and result-file hashes.
- Structural checks, duplicate-source rejection and a portable, static HTML report.
- LIV adapter: version-aware parsing of `laser-characterization-tools` CW exports
  with condition merging and raw-input provenance.
- A synthetic LIV export generated by the real `laser-liv` CLI, plus regression tests.

## Next: remaining export adapters

- LIV: extended diagnostics (input-hash verification against retained CSVs).
- PL presentation metrics: preserve Presentation / Raw Peak / Fit distinctions.
- Beam summaries: retain scan status, calibration, width and angle definitions.
- Spectral exports: explicit device/temperature mapping and spacing-rule semantics.
- Build a synthetic integration example using outputs from the actual tools.

## Later: research workflow

- Growth/process records, batch import and condition-aware device comparison.
- Analysis history and explicit raw-data availability.
- Traceable feature datasets and predictive baselines when suitable data exists.

These are future milestones. The current scaffold does not claim those capabilities.
